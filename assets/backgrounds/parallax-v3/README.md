# Фоны падения — 665

Три действующих мира: каменный (1), конфетный (3), магмовый (4).
Зимний фон `../world-2-ice-v2.webp` использован только как референс глубины;
зимний мир не добавлен. Палитры сверены с превью `assets/ui/world-terminal/preview-*-v4.webp`.

На мир приходится два отдельных изображения шириной 768 px:

| Мир | Дальний непрозрачный план | Ближние прозрачные уступы |
|---|---|---|
| Каменный | `stone-far.webp` | `stone-near.webp` |
| Конфетный | `candy-far.webp` | `candy-near.webp` |
| Магмовый | `magma-far.webp` | `magma-near.webp` |

Скорости относительно камеры: 0.08 и 0.26. Игровые блоки перемещаются с
камерой 1:1. У ближнего слоя прозрачный центр; он не закрывает дальнюю шахту.
Лёгкое затемнение внизу и прежние атмосферные частицы сохранены.

Слои повторяются с чередованием вертикального отражения: одинаковые края
стыкуются друг с другом. Границы соседних отрисовок общие, выровнены по
пикселю устройства, без полупрозрачных накладок и щелей.

Генерация: **built-in imagegen**, шесть отдельных вызовов; для `near` включён
настоящий прозрачный фон. Растровые оригиналы сохранены как `*-master.png`.
WebP получены уменьшением без обрезки и перерисовки.

Полные промпты:
[stone-far](stone-far.prompt.md), [stone-near](stone-near.prompt.md),
[candy-far](candy-far.prompt.md), [candy-near](candy-near.prompt.md),
[magma-far](magma-far.prompt.md), [magma-near](magma-near.prompt.md).

Просмотр движения: `editors/world-parallax-665.html`.
Проверка: `tools/test_world_parallax_665.cjs`; результаты и игровые кадры —
`outputs/world-parallax-665/`.
PNG-оригиналы и документация не входят в загрузочный манифест игры.
