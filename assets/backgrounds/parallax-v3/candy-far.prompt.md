# candy-far

Mode: built-in imagegen; opaque background.
References: assets/backgrounds/world-2-ice-v2.webp; assets/ui/world-terminal/preview-candy-v4.webp

Use case: layered background asset for a portrait 2D children's slime mining game with infinite downward movement. Reference image 1 is the successful WINTER cave DEPTH/COMPOSITION example only: open vertical abyss, broad distant silhouettes and side ledges, calm center, clean polished simple 2D cartoon painting. Reference image 2 is this active world's approved palette/material/style, not a UI screenshot. Use the SAME clear hand-painted 2D casual game style, chunky rounded natural forms, broad soft shading, matte colors, restrained highlights. This is a NONINTERACTIVE BACKGROUND behind brighter playable blocks and the slime. Low-to-medium contrast, no bright central object, no UI, text, icons, characters or gameplay tile grid. Portrait 2:3 composition intended to scroll vertically with no horizon, no floor, no ceiling arch closing the shaft, no doorway, no single unique focal landmark. Continue the vertical rock/column rhythm naturally beyond both top and bottom so vertical mirrored repetition is unobtrusive. Avoid details that obviously point down/up, obvious drips, hanging ropes, gravity-specific machinery, bridges, rails or lamps. No realistic granular texture, no crowded tiny details, no cinematic bloom. CANDY FACTORY CAVERN: muted plum/lilac and dark chocolate shadows with broad soft biscuit/caramel and berry-pink candy formations along sides. A few big smooth candy/wafer columns suggest the factory world without clutter, pipes or machine city. Pink accents are soft and desaturated behind gameplay, no neon, no bright white frosting. LAYER: FAR DISTANCE, OPAQUE full rectangle. A spacious deep shaft seen into the rock, layered large softened shadow silhouettes receding deep behind one another; darkest subdued distant middle, atmospheric blue/plum depth, inner side silhouettes broad and low-detail. NO close foreground walls, sharp ledges or bold edge framing: these will be on a separate transparent nearer layer. Keep all forms genuinely distant and quiet, avoid a flat wall texture directly behind the viewer. Very few medium-size accents distributed vertically, no flat black empty rectangle. Fill entire portrait canvas with opaque background, NOT transparent.
