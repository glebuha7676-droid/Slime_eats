# Редактор генерации

Из корня проекта запустите `node tools/generation/dev-server.cjs`, затем откройте
`http://127.0.0.1:8765/tools/generation/index.html`.

Редактор автоматически записывает сохранённые секции и маршруты в
`js/generation/generated-data.js`. Игра читает этот файл при загрузке, в том
числе при открытии через `file://`. Чтобы проверить новое построение шахты,
обновите игру и начните новый забег.

Если раньше секции редактировались через локальный `file://` адрес, сначала
откройте прежний адрес редактора и нажмите «Экспорт». Затем откройте редактор
через указанный выше адрес и нажмите «Импорт».
