# Работа с интерфейсом

При изменениях интерфейса этой игры сначала прочитать `docs/ui-style-guide.md`.
Там сохранены выбранный пользователем характер кнопок, иерархия, палитра,
правила контраста и локальные шрифты с кириллицей.

Сравнение шрифтов и образцы кнопок: `editors/ui-style-lab.html`.
Лаборатория является отдельной страницей для дизайна. Её шрифты и стили
не подключены автоматически к игре. Изменять игровой экран по текущему
запросу пользователя, сохраняя его принятые решения.
