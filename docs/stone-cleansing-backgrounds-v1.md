# Обычный мир: промежуточное очищение фона

Подготовлены три пары слоёв для оставшегося заражения75%,50%,25%:
интервалы ядра75–50%,50–25%,25–0%. Состояния100% и0% уже существовали
и не перегенерированы. Графика пока подготовлена отдельно от игрового рендера.

Игровые WebP768×1152 в `assets/backgrounds/stone-cleansing-v1/`:

- `stone-75-far.webp`, `stone-75-near.webp`;
- `stone-50-far.webp`, `stone-50-near.webp`;
- `stone-25-far.webp`, `stone-25-near.webp`.

Шесть файлов вместе324144байта. Дальний слой непрозрачный, ближний
имеет прозрачный центральный проход. Палитра и композиция утверждённой
заражённой пещеры сохранены через последовательное редактирование:
75% из100%,50% из75%,25% из50%. Корни постепенно убираются с тех же
мест, большие шипы исчезают, обнажается серая/землистая порода.

## Вертикальные стыки

Использован встроенный ImageGen. После основных генераций стык каждой
текстуры перенесён в середину через сдвиг на половину высоты и локально
перерисован. Окрестности внешних краёв рабочего offset сохранены, затем
половины возвращены на место. Нет отражений или подмены стыка туманом.

PNG-мастера1024×1536, локальные правки, точные промпты и сборка:
`output/concepts/stone-cleansing-background-v1/`.
Основные запросы — `prompts.json`, исправления стыков — `seam-prompts.json`.
`prepare-offsets.cjs`/`build.cjs` сохраняют воспроизводимую сборку.

Средняя разница RGBA соседних строк на стыке от0.325до0.720 из255;
обычная соседняя строка от0.327до0.774. Отчёт `seams.json` рядом.
