# Карусель, HP ядра и валюта · 28.10.2026

Баночка использует прежний WebP 256×256. На главном экране её размер
53×54 CSS px вместо 36×36; на узком экране 49×52. Она выступает за
светлую металлическую плашку высотой 44px. Количество стоит в отдельной
свободной колонке, тёмным Nunito 1000, без наложения на рисунок.
Баланс в меню, цены, ежедневные награды, колесо, итоги и счётчик в забеге
также получили более крупную баночку. У HUD сохранена отдельная ниша
энергии; под валюту выделено 70px (65px на узком экране).

Текущая планета на 12% крупнее по высоте доступной сцены, с ограничением
ширины; соседняя — 66% вместо 62%. Смещение соседей — 36% ширины сцены
вместо 39%. Прежняя круговая навигация на pointerdown сохранена.
Светлый номер мира с тёмными цифрами отделён от названия и HP.

Шкала ядра опущена, высота 24px (22px на узком экране). Четыре мягкие
продолговатые ячейки обозначают фазы без цифр снизу. Разделители мягкие,
с небольшим углублением; поверхность и мягкий блик общие для всей шкалы,
без выпуклой рамки вокруг каждой ячейки. «ЯДРО» и процент в отдельной нише,
оба меняют цвет вместе с заполнением. Вся заполненная
часть имеет цвет текущей стадии: >75 зелёный, >50 жёлтый, >25 оранжевый,
далее красный. После очищения — нулевое заполнение и здоровая планета.

Возврат: немедленный световой отклик ниши HP; 120ms — упругое сжатие
планеты и число урона; до 1250ms — уменьшение HP с тёплым отстающим
следом. При пересечении рубежа с 1450 до 2400ms — растворение в новой
стадии, мягкая локальная вспышка, увеличение и частицы, заметная подпись
«Аномалия отступает» / «Планета очищена!». Завершение 2850ms, без смены
стадии — 1850ms. Картинка следующей стадии готовится параллельно,
медленная сеть задерживает только преображение, а не начальный отклик.

Урон не применяется повторно: используется прежняя сохранённая очередь.
Меню, скрытая вкладка и результаты ставят показ на паузу; сброс отменяет
его. Reduced motion сокращает время, убирает пружину, частицы и вспышку.
