# Огонь, мороз и молния — баланс 606

## Постоянная база

| Мутация | Правило |
|---|---|
| Огонь | Три тика по 1 урону, через 1,2 / 2,4 / 3,6 секунды после поджигания. |
| Мороз | Касание превращает породу в снег; распространение выпускает ровно два осколка. Прежний шанс 35% сохранён. |
| Молния | Обычный удар по исходному блоку и цепь максимум по двум дополнительным различным блокам. |

Повторное касание горящего блока не пополняет запас тиков. Пламя переходит
только после разрушения на одного доступного соседа с общей стороной.
Предпочитает блок снизу, затем сбоку. Нет соседнего блока — цепочка заканчивается.
Диагонали, пустоты, опасные и неразрушаемые блоки не образуют мост для огня.
После третьего тика выживший блок гаснет; затухающее свечение не считается горением.

Один контакт на стыке блоков даёт одну цепь. Общее окно 72 мс соответствует
уже существующей защите физики от повторной обработки контакта.
Цепь не возвращается в исходный блок. В коротком тупике поражается столько
дополнительных целей, сколько действительно доступно, максимум две.

Эти правила одинаковы на всех стадиях внешности. Общая функция поджигания,
включая поджигание ультами огня, использует три тика. Происхождение урона
от ульты сохраняется на каждом тике и при переносе, чтобы не заряжать новую ульту.

## Перенос огня

Вместо кривой линии с кольцом летит маленький язычок пламени: тёплый шлейф,
яркое ядро, короткая вспышка и искры при попадании. Полёт — 220 мс;
целевой блок начинает визуально гореть при прибытии. Время эффекта совпадает
с часами горения даже при замедлении игры; пауза сдвигает обе шкалы.

Рисунок пламени и мягкое свечение создаются один раз в кешированных canvas.
Во время полёта используются готовые растры; живого blur и новых градиентов
на кадре нет. На слабых устройствах меньше элементов следа. Одновременно
показывается до шести переносов; ограничение рисунков не отменяет поджигание.

## Первая ульта молнии

Крест растёт от точки слайма на четыре клетки в каждую сторону за 260 мс.
Блок получает 1 урон при достижении фронта, один раз за активацию.
Проверка пересечённых расстояний сохраняет все попадания при низком FPS.
Пути четырёх лучей кешируются, рисуется только достигнутая часть;
на кончиках лучей есть яркие импульсы.

## Проверки

- `tools/test_elemental_balance.cjs`: расписание трёх тиков, отсутствие
  пополнения горения, перенос только после разрушения и без прыжков через
  пустоты, две дополнительные цели молнии, один разряд на контакт,
  два осколка и независимость базы от стадии.
- `tools/test_elemental_ultimates.cjs`: рост креста, урон по фронту,
  четыре клетки, отсутствие повторных попаданий, пауза и пропуск кадров.
- `tools/test_elemental_ultimates_browser.cjs`: настоящая отрисовка,
  скриншоты роста лучей и переноса огня, пауза и остальные стихии.
- Проверки массовых эффектов, жил мороза, стадий и заряда ульт.

Сборка: `dist/slime-yandex-606.zip`. Баланс требует дальнейших игровых
проверок по ощущениям; технические тесты подтверждают правила и границы,
а не равенство силы мутаций во всех ситуациях.
