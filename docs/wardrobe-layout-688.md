# Компоновка гардероба · 688

Изменения по уточнению пользователя, без генерации новых изображений:

- Слайм крупнее: вместо радиуса до 0.23 ширины / 0.30 высоты — до 0.29 /
  0.36 с ограничением по свободному месту над головой. Комната выше,
  точка ног опущена с 0.73 на 0.76 высоты исходника. Масштаб и cover-crop
  по-прежнему общие для изображения комнаты и живого персонажа.
- На холсте используется прежняя анимация главного экрана `slimeWait`
  (3.4 с, ease-in-out); опорная точка — ноги. Добавлено то же моргание
  с периодом 4700 мс. При reduced motion покачивание выключается.
- Синтезатор опущен: строка результата занимает место подсказки под
  заголовком аппарата, отдельного отступа под машиной больше нет.
  При открытии награды аппарат не прыгает.
- У коллекции ограничена высота; карточки прокручиваются внутри своего
  контейнера. Число элементов не ограничено раскладкой 3×2. Позиции двух
  вкладок сохраняются раздельно. Новый предмет автоматически показывается
  в этой прокрутке, не смещая окно. Поддержаны клавиатура, фокус и touch pan.
- На закрытых карточках существующий объёмный `assets/ui/lock.webp` и
  явная подпись «Закрыто», приглушённая поверхность. Выбор закрытой эмоции
  показывает «Эмоция закрыта» и «Откроется при синтезе», кнопка недоступна.
  Новых изображений аксессуаров и новых реакций не добавляли.
