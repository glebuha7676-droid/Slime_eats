# Очаг аномалии — графика v3

Палитра: прохладный фиолетовый и жёлто-лаймовая аномальная жидкость. Собственная флора: искривлённые светлые стволы, острые фиолетовые листья с лаймовыми концами и светящиеся семенные капсулы. Без смешения четырёх биомов.

100 → 75 → 50 → 25: одинаковый размер планеты и расположение объектов. Трещины начинаются с боков; растут утечки и свечение. 0 — взрыв, отдельной стадии 5% больше нет. Пульсация подсветки активна только у живого выбранного очага и учитывает reduced motion.

Ядро — плотные фиолетовые складки, сдавливающие светящуюся жидкость. Неровный пульс свечения, изменение масштаба меньше 1.5%, без вращения всей сферы. Свечение кешируется, без покадровых фильтров.

Блоки: пористый светло-фиолетовый хрупкий, цельный фиолетовый обычный, тёмный плотно-гранёный прочный. Зелёного в базовой породе нет. Заражённые жилы используют общий прозрачный слой +1/+3/+5.

Шахта: собственные дальний и ближний слои параллакса. Две сгенерированные опорные версии — исходная и с трещинами. Промежуточные состояния экспортированы смешением в WebP; в игре остаются два слоя с обычной отрисовкой. Те же правила генерации 500 м / 105 рядов, зоны 20/50/30 и хрупкие тоннели; новые опасности здесь не добавлены.

Исходники, промпты встроенного image_gen, сравнение стадий и скриншоты игры: `output/concepts/anomaly-source-v3/`.
