# Подготовка игры, версия 542

## Что изменено

- Новый фон загрузки: игровой слайм, огонь и молния, пробивание монолитной породы с синими жилами. Фон WebP, 339 КБ. Проценты и полоса — HTML/CSS, читаются отдельно от иллюстрации.
- До открытия игры загружаются 315 используемых ресурсов. Четыре сетевых запроса одновременно; готовность объявляется после загрузки файлов, декодирования первого экрана и подготовки слайма. При ошибке — повтор загрузки. Все изображения одновременно в память не декодируются: остальные раскрываются по мере использования.
- Еда получила отдельные игровые варианты 512 × 512, WebP с кодированием без потерь после уменьшения. Исходная еда 1254 × 1254 сохранена. Глаза и лица слайма не перекодировались.
- Единые адреса и версии ресурсов устраняют разные URL одного файла между предварительной загрузкой, CSS и игровым кодом.
- Во время сбора плазмы не перестраивается скрытый главный экран. Урон огня обрабатывает очередь горящих блоков, а не всю шахту каждый кадр. Адрес иконки способности меняется только при необходимости. Кэши оттенков глаз и щёк ограничены.
- Игровая физика и отрисовка ограничены 60 кадрами в секунду, включая экраны 120–240 Гц. Управление остаётся в основном игровом цикле; качество изображений этим ограничением не меняется.
- Исправлена ошибка первого чтения сохранения: нормализация больше не обращается к ещё не созданному состоянию обучения. Прогресс проверен после перезагрузки.
- Исправлен запуск падения после анимации портала при уже полученном сигнале паузы SDK. При сворачивании, потере фокуса и паузе платформы физика и звук останавливаются; возобновление учитывает все причины паузы.
- SDK и облачное сохранение ожидаются до готовности игры. При неудачном чтении облака запись в него отключается для этой сессии, чтобы не затереть непрочитанный прогресс. Реальная платформа не подменяет отсутствующую рекламу демонстрационной.

## Яндекс Игры

Проверены [технические требования](https://yandex.ru/dev/games/doc/ru/concepts/requirements), [подключение SDK](https://yandex.ru/dev/games/doc/ru/sdk/sdk-about) и [определение языка](https://yandex.ru/dev/games/doc/ru/requirements/2/14).

- Архив меньше ограничения 100 МБ без сжатия, имена файлов без кириллицы и пробелов, `index.html` в корне.
- SDK подключается через `/sdk.js`, предоставляемый платформой. В локальном просмотре и GitHub Pages используется автономный режим.
- `LoadingAPI.ready()` вызывается после реальной готовности; `GameplayAPI.start/stop` и события `game_api_pause/resume` обработаны.
- На платформе десктопное игровое поле касается верхнего и нижнего краёв. Мобильная страница не имеет внешней прокрутки. Игровое выделение текста, перетаскивание картинок и контекстное меню подавлены.
- Язык SDK читается при старте. Сейчас игра поддерживает русский; в карточке публикации следует указать только русский язык. Перевод на другие языки в эту работу не входит.
- Существующие награды за рекламу остаются через SDK; вознаграждение выдаётся только после `onRewarded`.

Это подготовка к публикации, не подтверждение прохождения модерации. Последний обязательный внешний этап — запуск этого ZIP в черновике Яндекса и проверка их отладочной панелью: настоящий SDK, реклама, облачные сохранения и события платформы. В локальном браузере поведение SDK проверено имитацией событий, настоящая платформа недоступна без загрузки в кабинет.

## Проверка

На ПК и в размере 390 × 844 проверены: первый экран, загрузка без пропавших изображений, отсутствие внешней прокрутки, сохранение после перезапуска, съедание трёх блюд и завершение превращения, запуск забега, возврат из результатов и пауза SDK до окончания анимации входа.

Измеренная загрузка на локальном сервере — около 1,8–2,3 с. Это не прогноз для мобильной сети и не результат на физическом слабом телефоне. В тесте игрового цикла входящие вызовы на частоте 240 Гц дают около 60 отрисовок.

Пройдены 14 проверок: загрузка/SDK, оптимизация, полнота ресурсов, превращение, разрушение опасностей ультами, заряд способности, сопротивление блоков, генерация первого мира и колючек, опыт, частицы разрушения, обучение, исчезновение несъеденной еды, нейтральная защита в старом состоянии сохранений. Генерация проверена на 250 вариантах. Синтаксис исходного и объединённого JS проверен; `git diff --check` без ошибок.
