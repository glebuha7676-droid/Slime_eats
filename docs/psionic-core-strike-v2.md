# Псионник: свечение и вырывание камня из стены

Аура больше не имеет огненной формы. Голубое рассеянное свечение из
палитры псионики, светлая середина,22 мягких голубых частиц (low/reduced8)
и отдельные световые частицы между слаймом и удерживаемой глыбой.
Кэш16 кадров256×256, запас под glow, без линий-контура и языков пламени.

Каждый следующий приём берёт камень с другой стороны. Сторона выбирается
один раз в `CORE.begin`; в течение сцены сохраняется. Камень появляется
частично погружённым в стену, world-якорь фиксируется на первом показе,
а не двигается вместе с камерой или слаймом. Около180–620ms — короткая
подготовка/напряжение, едва заметная дрожь камня. На620ms — вырывание:
толчок камеры, фиксация30–55ms, голубая вспышка, пыль и5/10 мелких
осколков с гравитацией. Они исходят из места вырывания в стене.

За540ms глыба резко подтягивается по дуге с быстрым началом и торможением.
Финальные X108 или332 — симметрично относительно шахты. Камень выше героя
на95px, не закрывает его лицо и «УДАРЬ!». После отделения раскрутка плавно
усиливается до~24rad/s. Направление вращения зеркально для двух сторон,
при броске сохраняется. Точка броска и след тоже учитывают выбранную сторону.

Размер глыбы по принесённой силе прежний. После тапа прежний тяжёлый бросок
с попаданием при реальном контакте, одним уроном и затуханием перед EVAC.
Энергия, награды и прогресс не менялись. Новых изображений нет: глыба и
осколки из существующей текстуры серого камня псионики. Новые blur/градиенты
не строятся в активном кадре. Пауза останавливает вырывание, осыпь и спин.

Проверки: `tools/test_psionic_core_strike.cjs` — обе стороны, удержание,
вырывание до670ms, раскрутка, фиксация/пауза, одна цель и один урон, EVAC,
малый запас, low/reduced,320/440px. `test_core_preparation_v2` — все формы.
Бюджет `tools/test_fire_style.cjs psionic`; превью `output/psionic-core-v1/`.
