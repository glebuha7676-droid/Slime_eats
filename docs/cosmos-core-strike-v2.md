# Космос: мягкая аура и сильное столкновение

Существующий кометный VFX III стадии сохранён. Для финального приёма
добавлен `softRim` при запекании: белые передние дуги и боковые штрихи
расширены, размыты и ослаблены. Частицы остаются читаемыми. Обычная
шахтная ульта использует прежние настройки painter.

Визуальная сила фиксируется в `CORE.begin`: четыре группы по принесённому
запасу. `<25 → .25`, `25–<50 → .5`, `50–<75 → .75`, `75–100 → 1`.
Размеры ауры/взрыва и отклик камеры используют эти группы; внутри группы
визуальная мощность одинакова. Ноль по-прежнему вызывает спасение без
удара. Формула фактического урона ядру остаётся существующей.

Столкновение: короткая фиксация 60–125ms, сильный локальный импакт,
фиолетовое облако плазмы с белой сердцевиной, мягкая волна и нерегулярный
разлёт искр. Двадцать небольших кадров облака запекаются из градиентных
текстур один раз, в кадре смешиваются соседние. Размер максимального
облака 610×360 логических px с мягкими прозрачными краями; малое заметно
скромнее. Белая сердцевина быстро гаснет, фиолетовый остаток — до 1s.
Reduced motion убирает вспышку экрана и сильный hit-stop; low-power
сокращает искры. Живого blur, построения градиентов и чтения пикселей нет.

Исправлена резкая смена позы при отражении: направление летящего хвоста
фиксируется до контакта и хвост быстро затухает без переворота на 180°.
Растяжение и наклон тела больше не следуют мгновенному скачку `vy` от
разгона к отскоку, а плавно переходят за 180ms. Небольшая ударная деформация
отдельная. Тряска для космоса — ограниченное затухающее колебание по
часам сцены вместо нового случайного смещения каждого нарисованного кадра.
На фиксации и паузе положение стабильно. Физический отскок и передача
скорости эвакуации сохранены.

Проверки: `tools/test_cosmos_core_strike.cjs` — границы четырёх групп,
1/5/25/50/100%, ручной/автоматический запуск, 30/60Hz, один урон,
направление хвоста после отражения, физический отскок, пауза,
reduced motion/low-power, 320/440px, бюджет рисования без живых градиентов.
Превью: `output/cosmos-core-v1/` (обновлено для v2).
