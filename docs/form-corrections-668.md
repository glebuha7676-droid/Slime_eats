# Новые вторые формы космоса и глитча · 668

Обе версии созданы через **встроенный ImageGen** с настоящей прозрачностью.
Оригиналы сохранены; игровые PNG/WebP не редактировались вручную.
Экспорт только подрезает прозрачные поля, равномерно масштабирует тело
и выравнивает его по ширине и нижней точке референса на холсте 512×512.

PNG-оригиналы находятся рядом с суффиксом `-master.png`.

Космос: локальная правка прежнего тела — удалена светлая нижняя линия,
низ продолжается мягкой зелёно-бирюзовой тенью до тёмного контура.
Каменные участки, кратеры и маленькие камни сохранены.

Глитч: новое тело по обычному силуэту слайма и мотивам III формы.
Пиксельные участки встроены в объёмное зелёно-бирюзовое тело. Прежняя
правка высоты 1.12 и дополнительное затемнение кодом удалены: используется
непосредственно новая графика с обычными пропорциями.

Экспорт: `tools/export_form_corrections_668.cjs`.
Проверка: `tools/review_form_corrections_668.cjs` — обе II формы загружаются
на главном экране и в сравнении трёх стадий; ошибок JavaScript нет.
Результаты: `outputs/form-corrections-668/`.
Космос выровнен по прежнему телу (нижняя точка 473); глитч — по обычному
слайму (нижняя точка 472). Лица и эффекты остаются отдельными слоями.
