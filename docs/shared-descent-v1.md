# Единый шаблон четырёх миров

Все игровые миры1/3/4/5 используют `SlimeWorld1Descent.build` напрямую.
Предыдущее наложение `biome-terrain.js` на старые сценарии поздних миров
больше не подключено к игре. Старый модуль сохранён как исходник прежней версии.

Общие правила:

- 500m,105 рядов,6 колонок, та же скорость падения305.
- Раскладка породы, обходы, плотный нижний пласт, интервалы угроз,
  боковые и центральные группы, горизонтальные/вертикальные патрули
  полностью совпадают при одинаковом зерне генерации.
- Колючки во всех мирах используют тот же спрайт и анимацию, прощающий
  хитбокс с отступом8%, одинаковый отскок,15% потери силы и800ms защиты.
  При обычном столкновении колючка не исчезает. Действие способностей,
  которые специально уничтожают опасности, сохранено.
- Нет гейзеров, метеоритных блоков, пружин, динамита, желейных/липких
  зон и аптечек в камне. Только3 подбираемых сгустка по12% силы.
- Во всех мирах валюта находится в жилах породы и выдаётся за разрушение,
  без временной раздачи колб в воздухе. Одинаковые наградные карманы
  и бюджет жил на раскладку.
- Обучение и его постановки остаются только в первом мире; обычные
  забеги четырёх миров используют один шаблон. Оформление блоков,
  фонов, атмосферы, планет и прогресс ядер сохранены.

Служебный gel в планировщике лишь резервирует место для восстановления:
`SlimeEnergyPickups.build` удаляет его до начала игры и расставляет сгустки.
В фактическом игровом поле живых специальных блоков нет.

Проверки: `tools/test_shared_descent.cjs` —50 зерён×4 мира, сравнение
каждой клетки/прочности/патруля/жилы/сгустка с первым миром, реальные
столкновения с колючкой, повторный контакт в защите, сбор валюты,
отрисовка на440/320px, загрузка всех спрайтов без404/исключений.
`tools/test_world1_descent.cjs` —250 раскладок исходного шаблона.
Результаты: `output/shared-descent-v1/`.
