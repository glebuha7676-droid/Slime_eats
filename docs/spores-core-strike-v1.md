# Споры — большая мина и грибовидный выброс

Выбран один большой взрыв: так приём отличается от последовательного
потока душ и быстро читается в конце каждого забега.

## Подготовка

2350ms. Прежние поза/лицо, перенос силы в жёлто-зелёную споровую ауру.
За телом растёт облако с объёмом из текущей графики спор. Вокруг пыльца,
редкие маленькие споры; передние облака только ниже лица.

С260ms семя выпускается из фактической позиции слайма. За650ms оно
долетает по дуге до оболочки ядра. Затем1150ms роста: одна большая мина
и мягкий ветвящийся мицелий на поверхности. Мицелий заранее запечён
из перекрывающихся органических зёрен, без прямых световых лучей.

## Взрыв

Общее нажатие и110ms удержания, затем короткое сжатие/раздувание мины.
На180ms один удар, который сохраняет урон. Мина быстро растворяется
в светлой вспышке. Из её места поднимается грибовидное облако: объёмный
столб из мягких клубов, широкая шапка, раскатывающиеся боковые облака
и разлёт спор/пыльцы. На максимуме шапка до620px, подъём до360px,
большая часть нижней камеры. На слабом заряде заметно компактнее.

1450ms вся фаза удара,380ms плавное затухание. После исчезновения
облака обычная потеря мутации и эвакуация. Без физического прыжка
в само ядро. Повторный клик не добавляет урон.

## Совместимость

Внутренний mutationId остаётся cloning, kind/spores — только приём.
Четыре визуальные силы по диапазонам0–24/25–49/50–74/75–100%.
Общая формула урона10–20% и прогресс планет не меняются. Добавлен
в админский просмотр. Все9 мутаций теперь имеют собственный приём;
общий нейтральный вариант остаётся запасным для отсутствующей силы.

Использованы существующие spores-giant-pod-v1, spores-giant-seed-v1,
spores-impact-cloud-v1. Новой генерации изображений нет. Сияния, мицелий
и мягкие клубы запекаются в небольшие кэши; живых градиентов/blur нет.
Частицы и слои ограничены, вне экрана отсекаются; low/reduced уменьшают
плотность и движение. Все часы связаны с игровым циклом и паузой.

Проверки: test_spores_core_strike, test_fire_style spores,
test_core_preparation_v2, test_core_encounter (запасной общий приём).
Записи слабого/полного заряда: output/spores-core-v1/.
