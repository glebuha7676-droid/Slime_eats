# Просмотр финальных ударов из админки

Кнопка «ПРОСМОТР УДАРОВ ПО ЯДРУ» в админ-меню сразу запускает падение
перед ядром. Это обычный `startDrop` и настоящий игровой цикл, CORE/VFX,
HUD силы, превращение и EVAC; отдельной копии эффектов нет.

Снизу компактная панель: повтор, пауза, настройки. В настройках мутация,
форма I–III, сила 0–100% с пресетами 5/25/50/75/100, три существующие
шахты и HP ядра (100/75/50/25/5). Изменение сразу повторяет сцену.
У мутаций без отдельного приёма написано «общий удар». После эвакуации
остаёмся в просмотре, без результатов или перехода на главный экран.
Выход — обновлением страницы. R — повтор, P — пауза; штатный тап по сцене
или Space/Enter выпускает приём. При редактировании полей горячие клавиши
не вмешиваются в ввод. Нулевая сила показывает потерю формы и спасение.

Режим копирует сохранение в память и блокирует `persist`, запись локального
сохранения, а также отложенную/выходную облачную запись. Урон по ядру
записывается только в текущий тестовый run. Финальная эвакуация не выдаёт
награды, не двигает кампанию и не сохраняет результаты.

UI: `js/ui/core-preview.js`, `css/core-preview.css`. Мост с настоящим игровым
циклом — `openCorePreview/startCorePreview` в `game.js`. Новых растровых
ассетов нет. Панель создаётся и обновляет статус только после входа.

Проверка: `tools/test_core_preview.cjs` — реальный вход через админку,
440/320px, свёрнутая/раскрытая панель, пауза, мутации/формы/заряды,
перезапуск, контакт и урон, ядро 5%, нулевая сила, отсутствие сохранений,
выход перезагрузкой. Скриншоты — `output/core-preview-v1/`.
