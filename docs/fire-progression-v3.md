# Огонь: развитие способности и первые ульты · 29.10.2026

Сделано только для огня. Остальные базовые способности пока сохраняют
прежний уровень2; общий план их изменения — mutation-roles-proposal-v1.md.

## Пассивная способность

Уровень огня берётся из достигнутой mutationLevel('fire'), фиксируется
при старте забега. Выбранная более ранняя ульта не понижает пассивку.
В меню мутации перечислены все три ступени.

- I: касание поджигает блок. Три удара по1 с интервалом1200ms.
  Если блок выжил, огонь гаснет. Распространения нет.
- II: при разрушении горящего блока огонь передаётся до четырёх
  непосредственно соседних клеток по кресту. Не по диагонали и не через
  пустоту. У новых очагов нулевой бюджет передачи — дальше не расходятся.
- III: тот же крест и один переход, но каждый зажжённый блок горит
  до разрушения. Колючки, непробиваемые и неподходящие специальные
  блоки огонь не принимает.

На одном корневом поджоге максимум исходный блок и4 соседа, независимо
от размера поля. Повторное касание активного огня не обновляет его время
и не возвращает бюджет передачи. Повторные обработчики разрушения
не распространяют огонь повторно. После полного угасания новый поджог
касанием считается новым действием игрока.

Обычные передачи заряжают ульту по общим правилам; огонь от ульты
и его потомки сохраняют исключение из накопления. Вне экрана тики
сохраняют механику; визуальный эффект рисуется только видимым клеткам.
III не использует бесконечные таймеры: количество оставшихся ударов
корректируется по конечному HP блока. Пауза сдвигает обычные часы огня.

## Ульты

I «Огненная волна»:800ms, направлена вниз по падению.420ms фронт
проходит четыре ряда, расширяется конусом до примерно трёх клеток.
Снимок исходной позиции. Растущий фронт поджигает каждую подходящую
клетку один раз; позади слайма не действует. Низкий FPS не пропускает
клетки. Вместо кольцевого эффекта — цельный мягкий огненный фронт,
18 кэшированных растровых кадров, мягкий след и небольшие искры.

II «Вулкан»: прежние4 камня и2350ms. Падение теперь на4.8/6.2 ряда
вперёд вместо3.6/4.85. Шире по горизонтали; у боковой стенки сохраняются
четыре разные точки приземления, а не пачка в одной точке. Краткое
движение вверх перед падением и существующая графика камней сохранены.
III «Феникс» и финальный удар по ядру не переделываются.
