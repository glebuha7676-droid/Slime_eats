# Счётчик, нажатие и подсказки синтезатора · 678

Полоска стала высотой 30 px. По центру всегда виден точный счётчик
`55 / 500` на контрастной тёмной основе, с табличными цифрами. Число
и доступный баланс обновляются сразу после нажатия. При получении колб
справа ненадолго появляется фактически добавленное количество `+10`.
В собранной коллекции счётчик показывает `9 / 9`.

Вместо порций 1, 2, 3… каждое нажатие добавляет **10 колб**. При удержании
ускоряется существующий интервал ввода, примерно от 500 до 170 мс,
а размер порции остаётся тем же. Отпускание немедленно останавливает ввод.
Порция ограничена остатком до заполнения и доступным балансом: например,
при остатке 5 списываются ровно 5, при доступных 3 — ровно 3.
Старый сохранённый `mutationInvestTapCount` больше не влияет на количество.
Дополнительная кнопка «Добавить всё» не нужна для этой схемы.

У корпуса есть короткий отклик на успешное нажатие: небольшое
продавливание на 180 мс. При приходе порции подчёркивается число на полоске.
Уменьшение движения отключает эти анимации; числа продолжают обновляться.

Подсказки на аппарате состоят из главного действия и короткой второй строки:

- `ДОБАВИТЬ 10 КОЛБ` / `ЗАЖМИ — БЫСТРЕЕ`;
- остаток меньше десяти: фактическая порция / `ДО ЗАПОЛНЕНИЯ`;
- мало колб на балансе: фактическая порция / `ДОСТУПНО СЕЙЧАС`;
- `НУЖНЫ КОЛБЫ` / `ДОБЫВАЙ ИХ В ШАХТЕ`;
- `КОЛБА ЗАПОЛНЕНА` / `НАЖМИ «СИНТЕЗ»`;
- `СИНТЕЗ МУТАЦИИ…`, `ПОДГОТОВКА ВЫДАЧИ…`, `ВЫДАЧА МУТАЦИИ…`;
- `МУТАЦИЯ ГОТОВА` / `НАЖМИ НА ЭМБЛЕМУ`;
- `НОВАЯ МУТАЦИЯ` / название.

Текст про смешивание цветов отсутствует. Принятые эффекты жидкости,
плазмы в трубе и выдачи не изменялись; меняются только UI и ввод колб.
