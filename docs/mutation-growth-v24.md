# Три источника мутагена и зрелый цветок v24

Уточнения пользователя заменяют схему v23. Жидкость должна нарастать от первой стадии к третьей, не заполнять первую стадию сильнее остальных. Все лозы и стебли — гладкая сливовая растительная ткань без шипов. Цвет жидкости остаётся исходным жёлто-лаймовым.

- +1: замкнутые лозы по всему периметру, три полураскрытых бутона на коротких стеблях немного к центру. Жидкость видна внутри каждого, из каждого капает немного — три отдельных источника. Маленькие лужицы увеличены после замечания о слабой заметности.
- +3: три более раскрытых чашевидных цветка с других сторон. Внутри заметно больше жидкости, капли и разливы обильнее. Стебли фиолетовые. Этот рисунок пользователь принял.
- +5: огромный зрелый цветок почти на весь блок с самым большим резервуаром, потоками по лепесткам и широким нижним разливом. Пользователь назвал третью готовой.

Графика `assets/ui/mutation-growth-v24/`. Банка v22 сохранена, награды 1/3/5 не меняются. Отдельный блок терний и игровые препятствия не меняются.

Мастера, точные промпты встроенного imagegen (включая уточнение первой стадии), сравнение на всех материалах при 64/32 px и кадры игры: `output/concepts/mutagen-growth-v24/`. Экспорт `tools/export_mutagen_growth_v24.py` отдельно измеряет площадь жёлто-лаймовой жидкости; проверка `tools/preview_mutagen_growth_v24.cjs` проверяет её рост по стадиям и загрузку в четырёх мирах при 440/320 px.
