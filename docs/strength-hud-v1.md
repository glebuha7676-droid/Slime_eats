# Сила и расстояние до ядра · 28.10.2026

Уточнение компоновки и суперсил: `run-clarity-v2.md` — расстояние теперь
отдельно под плашкой, верх высотой 58px, усиленные локальные отклики.

В забеге одна полоса — запас силы мутации. Слайм получает её из обработанной
аномалии вместе с формой. По исчерпании силы происходит прежняя эвакуация;
сохранённая сила определяет прежний урон по ядру. Баланс не менялся.

## Компоновка

Верхняя строка: сила, колбы, пауза. Вторая строка: «До ядра … м».
Плашка высотой 73px вместо 86px, без старого трека маршрута, стартовых
метров, общего километража, маленького слайма и финишного значка.
В бесконечном режиме вместо вычитания — «Глубина … м».
Для остаточного сценария с порталом предусмотрено «До выхода».

Крупный процент расположен над заполнением, на спокойном тёмном фоне.
Иконка совпадает со сгустком, который игрок подбирает в шахте. Зелёная
смесь за стеклом и фиолетовый пустой резерв связаны с общей аномалией.
Для рисунка используется уже существующий `flow-strip-v3.webp`, новых
тяжёлых изображений нет. Рисунок медленно движется туда-обратно, без шва.

## Отклик

- Процент и расстояние — целые числа с табличными цифрами. Пересчёт
  сглажен, покачивание меньше половины CSS-пикселя. На каждом метре
  анимация заново не запускается.
- Обычные столкновения спокойно уменьшают заполнение. Отстающий тёплый
  след показывает потерянную часть.
- Опасность: короткий красный отклик, лёгкое проседание числа и «−18%».
- Подбор: волна внутри стекла, светлый отклик, лёгкий подъём процента
  и «+18%» либо фактически восстановленное значение. При полной силе —
  «МАКС.», без ложного начисления.
- Обычный контакт с блоком не обрывает отклик подбора на следующем кадре.
- Подпись расхода/пополнения располагается слева в свободной нижней строке,
  не перекрывает ни процент силы, ни расстояние.
- До 35% — «МАЛО СИЛЫ», тёплое заполнение; до 18% — «СИЛА КОНЧАЕТСЯ»
  и спокойное красное предупреждение; при нуле — «НЕТ СИЛЫ» / «ДОМОЙ».
  Критическое число и ноль видны сразу, без задержки сглаживания.

Сглаживание использует один ограниченный RAF: он прекращается после
достижения значений и окончания короткого отклика. Пауза, верхнее меню,
скрытая сцена и вкладка останавливают движения. Reduced motion убирает
покачивание, волны и пружину; значения обновляются сразу. Новый забег
очищает старые события и цифры. Тексты для screen reader не объявляют
каждый метр, а отдельно сообщают только изменение состояния силы.
