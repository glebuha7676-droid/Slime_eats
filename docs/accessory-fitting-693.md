# Посадка и ресницы, 693

Ресницы сделаны кодом по уточнению пользователя: по три коротких прямых
штриха с округлыми концами, начинающихся на верхнем контуре каждого глаза.
Открытые глаза используют точки реального глазного спрайта; закрытые —
точки той же кубической кривой, что рисует веко. Реагируют на blink,
жевание, радость и предвкушение без отдельного таймера. Сами глаза/веки
не заменяются, матрица Canvas сохраняется. При hurt остаётся выражение
повреждения без дополнительных ресниц поверх крестиков.

Рендер: `js/rendering/slime-accessories.js`. Миниатюра для карточки
`assets/ui/wardrobe/accessories/lashes-code-v693.png` создана тем же кодом;
её экспортирует `tools/export_lash_thumbnail_693.cjs`. Старые сгенерированные
варианты ресниц сохранены как исходники, в игре не используются.

Предыдущие исправления посадки завершены: пиксельные очки уменьшены до
1.30 радиуса по ширине, центры ближе к центрам глаз. Новая компактная борода
`assets/ui/wardrobe/accessories/beard-v692.webp` (master рядом) расположена
под нижней губой, ширина .82 радиуса, верх .38 радиуса ниже центра лица.
Рот остаётся видимым и подвижным. Борода создана встроенным image_gen,
промпты: `assets/ui/wardrobe/accessories/prompts-692.json`.

Остальные предметы, экономика и структура гардероба сохранены.
`tools/test_accessory_details_693.cjs`: шесть штрихов, симметрия, синхронное
моргание/жевание/радость, подвижный рот, повязка и покупки без повторов.
`tools/test_accessories_693.cjs`: 330 сочетаний размеров и выражений,
594 сочетания мутаций и предметов, реальные примерка/сохранение/забег,
экраны 320×650, 390×844 и 1280×900.
Снимки: `outputs/accessories-693/new-accessories-blink.png` и
`outputs/accessories-693/wardrobe-lashes.png`.
