# Рост жидкости по контуру v23

Большой цветок +5 v22 понравился пользователю и сохранён без перерисовки. Новые первые две стадии показывают рост жидкости вдоль контура блока:

- +1: широкий разлив по всей нижней кромке, загибается вверх на обоих боках; два маленьких бутона.
- +3: жидкость поднимается по боковым краям к верхним углам и почти замыкает контур; средний раскрывающийся цветок внутри.
- +5: утверждённый большой цветок почти во всю клетку из v22.

Цвет мутагена исходный жёлто-лаймовый, корни гладкие сливовые, без шипов. Банка v22 сохранена. Новые ассеты только `assets/ui/mutation-contour-v23/infection-1.webp` и `infection-3.webp`; большой цветок и банка по прежним путям v22. Награды 1/3/5 не меняются.
