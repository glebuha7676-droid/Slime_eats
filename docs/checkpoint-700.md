# Чекпоинт 700 · 22 октября 2026

Мутация называется «Электро». Вторая стадия шаровой молнии наносит
2 урона каждому из двух выбранных блоков за импульс. Интервал 220 мс
вместо 350 мс, повторное поражение одной цели не чаще 440 мс. Линии
разряда чуть толще. Длина пути, время жизни и ограничения эффектов
сохранены; после зависшего кадра нет накопленного залпа. У второй
стадии Космоса 16 звёзд по 2 урона, только по одной цели без урона
по площади. Описания способностей соответствуют новым числам.

Конфетный и магмовый миры (внутренние ID 3 и 4) помечены «Скоро».
Есть превью, запуск закрыт независимо от сохранённых открытий.
Сохранение из такого мира возвращается в первый, сохраняя прогресс
и еду подготовленного забега. Прохождение первого мира не выдаёт
уведомление об открытии недоступного мира. Тесты урона выполняются
для доступных миров; запрет закрытых миров проверяется отдельно.

Лёгкая оптимизация:

- 110 игровых изображений повторно упакованы в WebP quality 90.
  Принимаются варианты, экономящие не менее 10% и с RGB RMSE ≤ 8.
  Все размеры сохранены, альфа-каналы побайтно совпадают. Кадрирование,
  посадка глаз/аксессуаров и координаты спрайтов не менялись.
- Изображения: 50 304 896 → 18 344 414 байт, экономия 31 960 482 байта.
  Оригиналы остаются локально в `outputs/optimization-700/originals/`.
  Это исходные материалы, они не нужны браузеру и не входят в релиз.
- Общая служба `SlimeUIActivity` приостанавливает анимации за верхним
  окном и на неактивном игровом экране. CSS-пауза имеет приоритет
  над прежними animation shorthand. WAAPI-анимации возобновляются,
  если они были остановлены именно этой службой.
- У гардероба, реактора и призрачных UI-эффектов нет холостого цикла
  рисования за другим меню; возобновление по событию видимости.
  Колесо не рисуется под другой вкладкой/окном. Начисление уже
  зарезервированной награды остаётся независимым от видимости.

Сборка `dist/slime-yandex-700.zip`: 334 игровых ресурса, 339 файлов,
около 21,2 МБ без сжатия и 19,1 МБ ZIP; один CSS и один основной JS.
