# Обучение 679: два приключения до свободного забега

Этот промежуточный сценарий заменён `docs/tutorial-current-680.md`:
по уточнению пользователя в первом спуске только управление и ульта,
опасности/лечение/жилы во втором, цель 100 поджогов, без замедления.

Для первого самостоятельного забега ребёнку нужны семь связей:
еда даёт силу; движение помогает выбирать путь; Огонь переходит на соседние
блоки; колючка снимает сердце; аптечка возвращает сердце; разрушение заряжает
суперсилу; задания и колбы открывают формы и новые мутации.
Каталог, все стадии, ускорение, другие миры и ежедневные награды не требуют
отдельных обязательных уроков в начале.

Сценарий:
1. Огонь I уже доступен. Перетащи еду → превращение → «Играть».
2. Первый спуск: безопасное управление → распространение Огня и цель 50 →
   видимая заранее колючка → аптечка → настоящая суперсила → развитие.
3. На главной готовый монитор ведёт к Огню II; подарок один раз оплачивает
   первое развитие. Объяснение формы и улучшенной суперсилы после результата.
4. Второй спуск: испытать усиление → видимая синяя жила → 25 настоящих колб.
5. Лаборатория появляется ради Мороза. Наполнение, синтез, выдача.
   Получение Мороза заканчивает обязательное обучение, новая еда доступна
   на главной для свободного следующего забега.

Постановка использует обычную генерацию шахты и её материалы. Локально
убирает лишние специальные блоки, готовит безопасные подходы и жилы.
Не заменяет шахту однородными рядами. Счётчики считают настоящие действия.
Камера не переносится к объектам: подсказки появляются только для уже
видимого объекта с запасом до столкновения. Скорость подсказок меняется
плавно, управление остаётся доступным. Обычные подсказки не модальные.
Пауза и пропуск доступны. Существующие законченные сохранения не перезапускаются.

Оформление: прежний палец, золотистая обводка, светлые карточки, Slime Nunito.
Круглые/обычные кнопки обводятся по форме, сложные рисунки — аккуратным
прямоугольником. Цель в спуске: эмблема, короткое действие, точные цифры,
полоска и обещание награды. Карточки не закрывают подсвеченный объект.

Проверка и результаты дополняются после реализации.
