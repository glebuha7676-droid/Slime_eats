# Фоны миров и порталы v4

Девять отдельных генераций встроенным ImageGen. Точные запросы и PNG
оригиналы: `output/concepts/world-backgrounds-v4/`. Там же список выбранных
файлов, размеров и веса `runtime-manifest.json`. В игру подключены только WebP.

## Миры

`assets/backgrounds/parallax-v4/`: по два изображения768×1152 на мир.
Скорости относительно камеры прежние: дальний план0.08, ближний0.26.
У ближнего настоящая альфа, центр прозрачный; игровая порода движется1:1.
Чередование вертикального отражения и выравнивание стыков по пикселю
устройства сохранены.

- Stone: обычная серая пещера с земляными прослойками, без синих жил.
- Candy: вафельная, шоколадная и ягодно-леденцовая геология под новые блоки.
- Magma: базальтовые столбы, застывшая красная лава, редкие лавовые просветы.
- Desert: собственные песчаные и терракотовые слоистые стены с пыльной глубиной.

Пустыня больше не использует каменный параллакс. Сцена в домашнем портале
строится из тех же новых слоёв выбранного мира. Старые ссылки parallax-v3
перенаправлены на v4, поэтому прежние варианты не попадают в загрузочный
манифест повторно. Новые растры всех миров вместе559036 байт.

## Возвращение

`assets/ui/portal-window-v2/laboratory-return.webp`,512×512,25830 байт.
Спокойная лабораторная комната с плоским полом и свободным центром, без
портала, пьедестала или центральной установки. Подключена к общему
рендереру возвращения, прибытия в шахту и эвакуации после удара/потери силы.

У эвакуационного портала150×150 вместо123×150. Портал прибытия116×116.
Общий рендерер дополнительно использует один диаметр для двух осей при
любых входных размерах; открытие/закрытие также масштабируется равномерно.
Порядок слоёв и затягивание слайма сохранены.

Все новые игровые изображения вместе584866 байт, около571KiB.
PNG исходники остаются вне runtime.
